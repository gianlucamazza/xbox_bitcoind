# Code of conduct

Be respectful and constructive. This is an unsupported hobby / Dev Mode project;
treat console and network use responsibly.

- Assume good faith; disagree on code, not people.
- No harassment, personal attacks, or discriminatory language.
- Security reports go through [SECURITY.md](SECURITY.md), not public issues.

Violations can be reported to the repository owner via the email on their GitHub
profile. The maintainer may edit, lock, or remove contributions that break these
rules.
